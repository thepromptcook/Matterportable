# Matterportable (Unity package)

Turns a Matterport link into a navigable, photoreal Unity environment.

1. **Window ▸ Matterportable ▸ Import Space**, paste a link such as `https://discover.matterport.com/space/rGMMnZDh3Tf`.
2. Click **Download & Create Scene**, then press **Play**.

Or add a **Matterport Space** component to any scene (GameObject ▸ Matterportable ▸ Matterport Space + Camera), paste
the link and press Play. It downloads on first use.

See the repository README for controls, the iteration workflow, troubleshooting and how it works:
https://github.com/thepromptcook/Matterportable
