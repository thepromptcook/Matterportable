# Matterportable (Unity package)

Turns a Matterport link into a navigable, photoreal Unity environment.

1. Press **Play** in an empty scene. The in-game menu appears.
2. Paste a link such as `https://discover.matterport.com/space/rGMMnZDh3Tf` and click **Open space**. It downloads on
   first use and opens instantly after that.

To put a space into a scene instead, use *GameObject ▸ Matterportable ▸ Matterport Space + Camera*, paste the link
into the inspector and press Play.

See the repository README for controls, the iteration workflow, troubleshooting and how it works:
https://github.com/thepromptcook/Matterportable
